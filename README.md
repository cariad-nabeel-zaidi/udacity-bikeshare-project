## Information about how to use your project

This code is a Python program for analyzing US bikeshare data. It prompts the user to select a city, month, and day to filter the data, then loads the corresponding CSV file into a Pandas DataFrame. It calculates and displays various statistics, including the most frequent travel times, most popular stations and trips, total and average trip durations, and user demographics such as types, gender, and birth years. The program runs in a loop, allowing the user to restart the analysis with new filters until they choose to exit.
